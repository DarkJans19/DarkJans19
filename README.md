## About me

I am a Systems Engineering student focused on **backend development, API engineering, and software architecture**. My experience spans requirements elicitation, object-oriented design, REST APIs, data persistence, containerized services, and technical documentation.

I enjoy understanding **why a system is designed a certain way**, not just making it run. Through academic projects, work with a real client, and hackathons, I have practiced translating requirements into software and explaining engineering decisions to different audiences.

- **Main direction:** Java / Spring Boot, Python / FastAPI, API design, and backend architecture.
- **Engineering interests:** clean and modular design, databases, testing, security, and cloud infrastructure.
- **Background:** collaborative full-stack work, data analysis, and applied machine learning.
- **Currently learning:** Agent loop engineering and strengthening my backend engineering practices.
